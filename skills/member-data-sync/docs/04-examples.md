## 字段映射

| 业务字段 | 系统字段 | 方向 | 说明 |
|---|---|---|---|
| 会员ID | 有赞会员 member_id（客户ID） | 读取 | 主键，用于与写回的标签记录对齐 |
| 手机号 | 有赞会员 mobile（手机号） | 读取 | 建议脱敏后使用，仅作触达联系方式 |
| 最近到店时间 | 交易订单 created_at（最近一笔已完成订单的下单时间） | 读取 | 以「已完成」状态的线下门店订单为准，取 MAX(created_at) |
| 消费次数 | 交易订单 count（近90天已完成订单数） | 读取 | 剔除退款订单，按 member_id 分组计数 |
| 累计消费金额 | 交易订单 sum(pay_amount)（近90天实付金额合计） | 读取 | 使用实付金额，不含运费与储值充值金额 |
| 储值余额 | 有赞储值账户 balance（储值余额） | 读取 | 注意区分「余额」与「累计充值」，取当前可用余额 |
| RFM分层标签 | 有赞会员标签 customer_tag（自定义标签组「会员分层」） | 写回 | 标签值为：高价值会员/潜力会员/一般挽留会员/流失风险会员 |
| 分层日期 | 有赞会员标签 标签备注或自定义字段 tag_date | 写回 | 记录分层计算日期，便于后续追踪标签时效 |

## 操作清单

1. 在有赞商家后台「客户-客户列表」导出近90天会员消费明细（含 member_id、手机号、订单时间、实付金额），或使用有赞开放平台「客户查询/订单查询」接口按天拉取。
2. 在储值模块导出（或经接口读取）各会员当前储值余额，与消费明细按 member_id 关联。
3. 将导出的原始数据交给 RFM 分层环节计算，得到每位会员的分层标签。
4. 在有赞后台「客户-客户标签」中创建自定义标签组「会员分层」，包含四个标签值。
5. 按分层结果为对应会员批量打标（后台支持按表格导入打标，或调用客户标签设置接口逐个写入），同时写入分层日期。
6. 打标完成后抽样核对 5-10 名会员，确认标签与分层结果一致。
