# 会员数据对接

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_06_sk01` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 会员唤醒师 |
| 能力族 | — |
| 复杂度 | `M` |
| 阶段 | `P1` |
| 复用度 | 高（预约排班调度员、日报分析师共用） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

收银/会员系统数据读取（BusinessConnector）

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `system` | string | ✅ | 需要读写的系统名称（如企业微信、抖店后台） |
| `task` | string | ✅ | 要读什么、要写什么 |

## 输出规格

连接器数据读写

- `field_map`：系统字段与资产字段的对应关系
- `operation`：用户需要在其平台上执行的步骤
- `limitation`：明确声明本资产不能自动完成该操作

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

```markdown
## 字段映射

| 业务字段 | 系统字段 | 方向 | 说明 |
|---|---|---|---|
| 会员ID | 有赞会员 member_id（客户ID） | 读取 | 主键，用于与写回的标签记录对齐 |
| 手机号 | 有赞会员 mobile（手机号） | 读取 | 建议脱敏后使用，仅作触达联系方式 |
| 最近到店时间 | 交易订单 created_at（最近一笔已完成订单的下单时间） | 读取 | 以「已完成」状态的线下门店订单为准，取 MAX(created_at) |
| 消费次数 | 交易订单 count（近90天已完成订单数） | 读取 | 剔除退款订单，按 member_id 分组计数 |
| 累计消费金额 | 交易订单 sum(pay_amount)（近90天实付金额合计） | 读取 | 使用实付金额，不含运费与储值充值金额 |
| 储值余额 | 有赞储值账户 balance（储值余额） | 读取 | 注意区分「余额」与「累计充值」，取当前可用余额 |
| RFM分层标签 | 有赞会员标签 customer_tag（自定义标签组「会员分层」） | 写回 | 标签值为：高价值会员/潜力会员/一般挽留会员/流失风险会员 |
| 分层日期 | 有赞会员标签 标签备注或自定义字段 tag_date | 写回 | 记录分层计算日期，便于后续追踪标签时效 |

## 操作清单

1. 在有赞商家后台「客户-客户列表」导出近90天会员消费明细（含 member_id、手机号、订单时间、实付金额），或使用有赞开放平台「客户查询/订单查询」接口按天拉取。
2. 在储值模块导出（或经接口读取）各会员当前储值余额，与消费明细按 member_id 关联。
3. 将导出的原始数据交给 RFM 分层环节计算，得到每位会员的分层标签。
4. 在有赞后台「客户-客户标签」中创建自定义标签组「会员分层」，包含四个标签值。
5. 按分层结果为对应会员批量打标（后台支持按表格导入打标，或调用客户标签设置接口逐个写入），同时写入分层日期。
6. 打标完成后抽样核对 5-10 名会员，确认标签与分层结果一致。

## 能力边界

本资产为纯提示词形态，不能真实读写有赞系统：无法登录有赞商家后台、无法调用开放平台接口、无法导出或写回任何数据。以上仅产出字段映射与操作清单，实际读取与写回须由用户在有赞后台用平台连接器（或人工导出/导入）完成。涉及会员手机号属个人信息，导出与使用请遵守个人信息保护相关要求。


```
