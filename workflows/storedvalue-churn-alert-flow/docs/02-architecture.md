# 储值流失预警 · 业务架构图

## 一、在整体架构中的位置

本复合技能（工作流）位于数字员工「会员唤醒师」的能力层：

```mermaid
flowchart TB
    U["餐饮、美业、休闲娱乐等线下门店经营者"] --> DE["数字员工<br/>会员唤醒师"]
    DE --> AS["复合技能（工作流）<br/>储值流失预警"]
    AS --> KB["私有知识库<br/>RAG wiki"]
    AS --> OUT["交付物<br/>人工审核后使用"]
    KB -.增强.-> AS
```

## 二、四层结构

| 层 | 内容 | 本资产的落点 |
|----|------|-------------|
| 用户层 | 餐饮、美业、休闲娱乐等线下门店经营者 | 使用者 |
| 资产层 | 数字员工 = 技能 + 工作流 + 知识库 + 连接器 | 所属员工：会员唤醒师 |
| 能力层 | 原子技能 / 复合技能 | **本资产在此层** |
| 数据层 | 私有知识库 + 连接器数据 | 见 `knowledge/` `connectors/` |

## 三、依赖关系

```mermaid
flowchart LR
```

## 三·补充：编排依赖（本工作流调用的原子技能）

|---|---------|---------|------|

## 四、非功能属性

| 属性 | 说明 |
|------|------|
| 运行位置 | 用户端（浏览器 / 客户端），无服务端 |
| 数据流向 | 数据仅在用户的 AI 会话内处理，不经过任何第三方服务器 |
| 依赖 | 无运行时依赖；测试仅需 pytest |
| 合规 | 内置合规区块；连接器只走官方 API / 用户导出数据 |
